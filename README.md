# landingform

Página de captura de iscas da AVIX (`/material`). Site estático, sem build, publicado no Vercel.

- `material/` página, estilos, script e `config.js` (N8N_URL, NUMERO_ALEX, POLITICA_URL)
- `tokens.css` e `colors_and_type.css` tokens do design system da AVIX
- `assets/` logos

Testar sem o n8n: `/material?isca=calc-leads&mock=1` (extras: `&mock_delay=4000`, `&mock_post=erro`).
